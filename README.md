Portillo's Portfolio: Python Projects & Data Filters
Welcome to my first programming portfolio! This repository is a collection of 5 distinct Python applications that demonstrate my foundational programming skills. These projects showcase my ability to handle user inputs, implement conditional logic, mimic real-world systems, and—most importantly—efficiently filter large data sets.

Featured Projects: 

1. Beverage Dietary Finder (create.py)
An interactive utility designed to help users find drinks that perfectly align with their dietary restrictions or preferences.
Core Concepts: User input handling, conditional logic (if/elif/else), and data matching.
Why it matters: Demonstrates an understanding of user-centric design and basic categorization.
2. Multi-Log Big Data Filter (heatwave.py)
This project highlights my ability to parse, manage, and isolate specific information from large, noisy data sets. It processes three distinct types of data:
Temperature Records: Isolating specific anomalies or ranges.
Traffic Volumes: Filtering peak hours or congestion thresholds.
Security Logs: Flagging potential risks or specific event types.
Core Concepts: File I/O (handling data sets), loops, boolean logic, and optimization.
Why it matters: Proves I can scale code to handle real-world backend tasks, data analysis, and log parsing.
3. Personalized Dog Matcher (imagerec.py)
A recommendation engine that takes users through a questionnaire about their lifestyle, living space, and energy levels to output the ideal dog breed for them.
Core Concepts: Complex nested logic, scoring systems, and data mapping.
Why it matters: Showcases how to translate subjective user preferences into objective programmatic outcomes.
4. Interactive Mad Libs Game (madlib.py)
A digital twist on the classic word game. The program prompts the user for various parts of speech (nouns, verbs, adjectives) and weaves them into a hilarious, unpredictable story.
Core Concepts: String manipulation, concatenation, and dynamic text rendering.
Why it matters: A fun demonstration of text-based UI and variable tracking.
5. Casino Slot Machine Simulator (slotmachine.py) 
A text-based simulation of a classic casino slot machine, featuring virtual currency, random reel generation, and payout logic.
Core Concepts: The random module, state management (tracking the user's balance), and game loop mechanics.
Why it matters: Shows an understanding of probability mechanics and maintaining a continuous application state based on user risk.

Skills Demonstrated:

By building these projects, I have developed and practiced:
Data Manipulation: Cleaning and isolating specific metrics out of massive logs.
Control Flow: Mastering loops, switches, and complex conditional statements.
Randomization & Logic: Creating unpredictable outcomes for gaming simulations.
User Experience (UX): Crafting clean command-line interfaces (CLI) that guide users smoothly through inputs.
